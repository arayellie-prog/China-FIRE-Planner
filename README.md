# China FIRE Planner

A privacy-first Agent Skill for building a readable personal financial baseline for people in China.

V0.1 focuses on onboarding, local Financial Profiles, deterministic baseline calculations, readable Chinese reports, and the Financial Portrait feature. It does not connect financial accounts, recommend securities, or promise returns.

User data belongs outside this Skill directory. Never commit a real `profile.yaml`, `snapshots.csv`, review, or statement export.

## Use

Invoke the skill as `$china-fire-planner` and specify the interaction style you prefer. For example:

> 使用 $china-fire-planner 帮我做第一次财务体检。请用中文，最后生成一份口语化、容易读懂的报告。

See `references/` for the schema, onboarding report, privacy rules, and Financial Portrait guidance.
